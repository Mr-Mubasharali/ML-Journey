# 🔧 Feature Engineering

This folder contains my hands-on learning and implementations of **Feature Engineering techniques** used in Machine Learning.

Feature Engineering is an important step in the ML pipeline because the quality and representation of features can significantly affect model performance.

## 📂 Topics Covered

### 1. 🧩 Handling Missing Values
Understanding how missing values affect a dataset and different techniques to handle them.

- Missing value detection
- Missing value percentage
- Complete Case Analysis (CCA)
- Mean Imputation
- Median Imputation
- KNN Imputation
- MICE (Multiple Imputation by Chained Equations)

### 2. 📊 Imputation Techniques

| Technique | Description |
|----------|-------------|
| **CCA** | Removes rows containing missing values |
| **Mean Imputation** | Replaces missing values with the mean |
| **Median Imputation** | Replaces missing values with the median |
| **KNN Imputer** | Uses similar observations to estimate missing values |
| **MICE** | Iteratively predicts missing values using other features |
